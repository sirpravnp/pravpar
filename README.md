# pravpar
Personal site: essays and projects. Static, built with a tiny Node script and deployed by GitHub Actions to GitHub Pages.

- Edit the bio and projects: `src/index.html`
- Write an essay: add `content/essays/<slug>.md` with `title`, `date` (YYYY-MM-DD) and optional `summary` front matter
- Preview locally: `npm install && npm run build`, then serve `dist/`
